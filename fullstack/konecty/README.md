# Konecty - Full Stack

## Pré-requisitos
Antes de começar, certifique-se de ter os seguintes requisitos instalados:

- [Node](https://nodejs.org/en)
- [NPM](https://www.npmjs.com/) ou 
- [Yarn](https://yarnpkg.com/) 

## Considerações sobre o projeto

- O Next.js foi utilizado para gerenciar tanto o lado cliente quanto o lado servidor.
- Todos os requisitos foram atendidos.
- Como base para listagem de produtos, foi usado os dados do repositório [goat-sneakers](https://github.com/Stupidism/goat-sneakers/tree/master?tab=readme-ov-file)
- Testes unitários foram adicionados para todos os componentes.
- Foi pensando em estratégias de melhorar SEO.
- A experiência do usuário foi um critério fundamental, especialmente na versão mobile.

## Como rodar o projeto

```bash
# Clone o repositorio
$ git clone https://github.com/peidrao/konecty-jobs.git
# entre no diretorio
$ cd konecty-jobs/fullstack/konecty/
# Instale dependências do projeto
$ npm install 
# ou
$ yarn install
# após instação de dependências, rode
$ npm run dev
# ou
$ yarn run dev 
```
